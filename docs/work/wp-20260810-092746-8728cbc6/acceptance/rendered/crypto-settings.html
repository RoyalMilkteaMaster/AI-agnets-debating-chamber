設定檔內的說明

這些是 JSON 裡以底線開頭的註解欄位，本頁只顯示，不修改。

（最外層）
辯論時間門檻、票數階梯與燈號規則的唯一來源。改門檻只動這個檔，程式不得複製字面值。時間單位為毫秒，起點是該 run 的 T+0。
timeline_ms
debate_start 是單幣題的預設封存時刻；實際起跑點以該 run 的封存時刻為準（research_scheduler.research_deadlines 是封存時刻的唯一權威）。round_one_window 是相對窗，第一輪牆＝該 run 封存時刻＋這個窗。其餘四個是絕對牆。
vote_thresholds
採納立場所需的絕對票數。unanimous_blind_pass 是開場盲投直過的門檻：七席開場全部發布、還沒有任何辯論訊息，而且同一立場的開場票數達到它時，直接停止產報告。initial／reduced／forced_stop 是辯論後的有效票階梯，三者必須嚴格遞減；initial 從辯論開始生效，reduced 從 timeline_ms.reduced_threshold_from 生效，forced_stop 在 timeline_ms.force_stop 強制結算時生效。
confidence
ADR 0003 的純票數燈號制，report_contract.confidence_cap 的唯一來源。min_votes 比對的是最終採納立場的有效票數，不是全場有效票數。light_scale 由好到壞排序，最後一級的 min_votes 必須是 0；降級＝沿著這個順序往後移 levels 格，末端夾住。級別字串本身（有哪些燈、誰比誰好、配哪個圖示）由 report_contract.CONFIDENCE_LEVELS 擁有，本檔只決定「幾票對哪一級」，兩者必須逐字一致且同序，否則載入時就會被拒絕。
confidence.downgrades
ADR 0003 只保留這兩條，判定範圍是採納立場實際引用的證據卡。刪掉整條規則就是關掉它。exempt_seat_ids 內的席位貢獻的證據卡不參與該條規則的判定（輿情席職責就是蒐集三手輿情訊號，對它套用來源等級降級屬於誤殺），這個欄位只有逐卡判定的 low_trust_source 有；few_independent_domains 數的是網域集合基數，豁免會讓集合變小、反而更容易降級，因此不提供該欄位。
