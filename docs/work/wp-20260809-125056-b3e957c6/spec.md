## 問題

前端經多輪改動後動線混亂。工作區根目錄的靜態快照 `辯論室預覽.html` 誤導使用者以為規則已過期、報告點不開；`開啟辯論室.bat` 啟動後留下關不掉的主控台黑框。七席的名稱與研究方向仍是純幣圈視角，與系統已支援台股／美股／開放題的現實不符，台股題會印出幣圈席名。發問依賴純文字解析猜使用者的標的。離線報告只有 HTML，不方便直接交給別人。

使用者是本人（本機單人使用）；離線報告的讀者是使用者要分享的對象。

第七席的舊職能「反方證據與資料品質檢查」定位不合理：立場尚未形成就先找反證。相似資訊面由同一模型家族研究，會犯同一種錯。

## 目標

- 視覺一致、入口乾淨無黑框、頁面精簡的前端。
- 七席隨題目的資產類別自動換套顯示名稱與研究方向，webapp 與離線報告一致。
- 發問改用標的選單，取代純文字資產解析。
- 離線報告可手動匯出 PDF。

核心流程：雙擊桌面捷徑（隱藏視窗）→ 瀏覽器開主頁 → 選單選資產類別＋標的發問 → 一頁式辯論室觀戰 → run 產出後右上角開市場報告／完整辯論，需要時按「匯出 PDF」→ 畫面上「關閉伺服器」優雅收工。

## User Stories

1. 身為使用者，我希望雙擊桌面捷徑就能啟動辯論室且不留主控台黑框，以便開始分析時畫面乾淨。
2. 身為使用者，我希望伺服器已在跑時捷徑只開瀏覽器、不重複啟動，以便避免重複程序與埠衝突。
3. 身為使用者，我希望在頁面右上角按「關閉伺服器」就優雅收工並照常寫 `server_stop`，以便不必回終端機找程序。
4. 身為使用者，我希望有備援的「關閉辯論室」捷徑，以便頁面打不開時仍能停掉伺服器。
5. 身為使用者，我希望根目錄不再有會誤導我的靜態快照檔，以便不會再對著過期畫面判斷規則。
6. 身為使用者，我希望用資產類別選單加標的選取來發問，以便系統不必猜我的標的。
7. 身為使用者，我希望曾經跑過的標的出現在建議清單裡，以便重複追蹤同一標的時少打字。
8. 身為使用者，我希望台股與美股題目的七席顯示股票語彙的名稱與研究方向，以便席位分工看得懂、與市場現實一致。
9. 身為使用者，我希望幣圈題目維持現行幣圈語彙，以便既有使用習慣不被破壞。
10. 身為使用者，我希望 webapp 與離線報告顯示同一套席位名稱，以便分享出去的台股報告不會出現幣圈席名。
11. 身為使用者，我希望第七席改做基本面研究，以便投票前不再有「立場未出就先找反證」的席位，同時品質把關仍在。
12. 身為使用者，我希望歷史與命中率併成一頁（上方統計卡、下方 run 列表帶命中結果），以便一次看完成績與紀錄。
13. 身為使用者，我希望舊的 `/stats` 網址仍可用並自動轉到合併頁，以便舊書籤不失效。
14. 身為使用者，我希望在報告頁按「匯出 PDF」就把現成 HTML 轉成 `report.pdf` 與 `debate.pdf` 存進該 run 資料夾，以便直接把檔案傳給別人。
15. 身為使用者，我希望全部網頁頁面套同一套設計系統，以便各頁視覺一致、不像拼裝。
16. 身為使用者，我希望動態聊天室、燈位與正方／反方／無法判斷票數的行為完全不變，以便專案主題（辯論框）不因改版走鐘。
17. 身為使用者，我希望畫面全繁體中文、不出現英文資料原值，以便不用猜欄位意思。
18. 身為使用者，我希望沒產出報告的 run 在歷史列表顯示狀態、主頁能回看聊天過程，以便失敗的 run 也追得回去。

## 需求與行為

### R1 頁面清單與合併頁

網頁前端只保留以下頁面：

| 頁面 | 內容 |
|---|---|
| 即時辯論（主頁） | 一頁式即時辯論室，含發問區 |
| 歷史與命中率 | 合併成單一頁面：上方統計卡、下方 run 列表帶命中結果 |
| 設定 | 規則調整 |
| run 詳情 | 功能保留現況，版面套新設計系統（R3 適用於所有網頁頁面） |
| 市場報告／完整辯論 | 離線兩份，內容不碰、右上角必可點 |

- 原歷史查詢頁與命中率統計頁合併為「歷史與命中率頁」。
- 手動記錄結果的表單併入合併頁。
- 沒產出報告的 run：歷史列表顯示其狀態；主頁可回看該 run 的聊天過程。

### R2 保護區（功能凍結、外衣可換）

以下三項**功能凍結**：

- 動態聊天室
- 燈位
- 正方／反方／無法判斷票數

**內容、位置、語意色不動**。可以動的只有字體、間距、卡片樣式——隨新設計系統統一。任何行為、門檻、計票、燈號語意的改動都不在本次授權範圍。

### R3 全站設計系統

全部網頁頁面套同一套新設計系統。語意色（bull／bear／五燈）保留語意，只校準色階。系統字型堆疊，不引入任何外部資源（無 Google Fonts、無 CDN）。

設計方法：以 ui-ux-pro-max-skill 產出設計系統方向（金融場景風格／配色／字體決策），以 taste-skill 做排版與密度紀律的執行審計。

### R4 入口動線改造

- 刪除工作區根目錄的 `辯論室預覽.html`。
- `開啟辯論室.bat` 退役（刪除）。
- 桌面捷徑隱藏視窗啟動；偵測到伺服器已在跑時，只開瀏覽器、不重複啟動。
- 頁面右上角新增「關閉伺服器」按鈕，走優雅停機路徑，照常寫 `server_stop`。
- 提供備援的「關閉辯論室」捷徑。
- 伺服器仍為前景程序模型；關閉一律走優雅路徑。

### R5 七席換套

兩套研究方向：股票套（台股與美股共用）、幣圈套（現行語彙）；依 run 的資產類別自動切換顯示名稱與方向。`seat_id` 與 `output_dir` 永不改（相容性底線）。

開放（open）套的內容**在此明定**（解決「三套 fail-closed 必齊」與「範圍外不設計中性套」的表面矛盾）：前六席沿用現行 roster 的通用敘述與幣圈套顯示名稱，第七席顯示名稱「基本面研究員」、方向「關鍵數據與事實查核」。open 套因此是**有內容的一套**，fail-closed 驗證可通過；範圍外排除的只是「為開放題重新設計中性方向」這件事。

### R6 標的選單

發問改為以選單選定資產類別，再選／填標的，取代純文字資產解析。接 T05 的 `assets`／`asset_class` 接縫。標的輸入依資產類別給對應格式提示；建議清單來自過往 run 的標的——**取得方式**：webapp 呼叫既有 `run_index.query_runs` 後在 Python 端對標的欄位去重，不新增 SQL、不擴充 `run_index`（維持零 SQL 與唯一取數路徑）。

### R7 全繁體中文

畫面上不得出現英文資料原值。標籤必須從既有權威帶出，不得在前端建第二份詞彙表。權威沒有涵蓋的值要有明確處理方式並說明，不得靜默 fallback 成英文原值。

### R8 PDF 手動匯出

報告頁提供「匯出 PDF」按鈕，以 Edge 無頭模式把該 run 現成的 HTML 轉成 `report.pdf` 與 `debate.pdf`，存入該 run 資料夾。HTML 與報告版面不動。

### 邊界與錯誤

- 離線報告 renderer（`report_renderer.py`、`report_audit_renderer.py`）與 `run_verifier.py` 的版面與內容不動。**唯一開口**：席位標籤來源須支援換套，台股報告不得印幣圈席名。
- PDF 匯出成為 run 資料夾第三個寫入路徑（現行唯二：launch 起子程序、`outcome.json`）；只新增 `.pdf`，不改任何既有檔案；不得踩到 `run_verifier` 的檢查。
- 匯出失敗時回誠實錯誤頁，不得留下半成品檔或假稱成功。

### 產品限制

- webapp 零 SQL；唯一取數路徑是 `run_index.query_runs`。
- run artifact 唯讀。
- CSP 逐 directive 釘死、零 inline script。
- WCAG AA 對比度是測試斷言，不是目視判斷。
- 規則值一律走 reload-aware API 讀取，不得在模組層凍結。
- 既有測試全綠。
- 不引入外部資源，使用系統字型堆疊。

## 實作決策

### 資料與所有權

- `config/agent_roster.json` 是席位資訊的**單一權威**：`seat_id`、`output_dir`、提供者、以及每席的 `profiles`。散落在其他模組的席位標籤寫死表全部刪除。
- 設計 token（色彩／字級／間距）以資料形式落在 webapp `pages.py`，沿用既有 `THEMES` 模式；不散進各頁字串。
- run artifact 維持唯讀。run 目錄的核准寫入路徑由兩條（launch 起子程序、`outcome.json`）增為三條，第三條只新增 `.pdf`。
- run 查詢資料的唯一取數路徑仍是 `run_index.query_runs`；webapp 內零 SQL。
- 詞彙權威不新增第二份：資產類別看 `config/market_scopes.json`，燈號看 `report_contract.CONFIDENCE_LEVELS`，立場看即時頁既有的立場語彙表（每種題型有自己的語彙），席位名稱與方向看 roster `profiles`。
- Log 沿用既有架構（§11.8），本次不新建。

### 模組責任與公開介面

- `seats.py`：`load_roster` 擴充為讀取 `profiles`，載入時 **fail-closed** 驗證（七席齊、每席三套齊、每套具備 `display_name` 與 `focus`），缺任何一項就拒絕啟動而非降級。對外提供「依資產類別取得席位顯示名稱與研究方向」的單一讀取口；模組內原有的顯示常數刪除。
- `report_renderer.py`：刪除席位標籤寫死表，標籤解析改走 roster 讀取口。**這是離線報告唯一被允許修改的地方**，版面、章節、輸出內容一律不動。`report_audit_renderer.py` 同一開口，`run_verifier.py` 不動。
- webapp `pages.py`：持有設計 token 表；全站收斂為單一樣式表（辯論室原本隔離的樣式併入）；合併頁與各頁版面由此產生。
- webapp `views.py`：負責合併頁的資料整形（統計卡、run 列表帶命中結果、手動記錄結果表單），routes 不含查詢邏輯。
- webapp `server.py`：路由與端點；新增 PDF 匯出與停機端點，並處理 `/stats` 轉跳。
- webapp 新增 PDF 匯出模組：接受可注入的轉換器，把該 run 現成 HTML 轉為 PDF；預設實作為 Edge 無頭模式，在 WSL 下以 `wslpath` 轉換路徑。
- `launcher.py` 接縫：標的表單送出後，以 T05 的 `assets`／`asset_class` 參數啟動 run；webapp 端不再執行純文字資產解析。
- Code Root `scripts/`：承載啟動與關閉邏輯，工作區根目錄現行的 `start-webapp.ps1` 併入此處。工作區根目錄只留兩個捷徑：「開啟辯論室」（隱藏視窗；偵測已在跑則只開瀏覽器）與「關閉辯論室」（備援，打停機端點）。

### Schema、API contract 與系統互動

- **roster schema 升版**：每席新增 `profiles`，含 `stock`／`crypto`／`open` 三套，每套為 `{display_name, focus}`。`seat_id` 與 `output_dir` 的欄位語意不變。提供者對調（onchain 席→claude、news 席→codex）在同一批完成，維持 3／3／1。
- **套組選擇規則**（單一判定處，不得複製）：`tw_stock` 與 `us_stock` → stock；`crypto` → crypto；`open` 或跨類 → open。
- **顯示規則**：所有 run（含歷史 run）一律以**現行套組**顯示；不回溯保存當時的套組。
- **端點契約**：
  - `GET /history`：歷史與命中率合併頁。
  - `GET /stats`：302 轉跳 `/history`。
  - `POST /run/<id>/export-pdf`：成功時在該 run 目錄產生 `report.pdf` 與 `debate.pdf`；失敗回誠實錯誤頁。
  - `POST /shutdown`：先回覆「已關閉」頁面，再優雅停機，照常寫 `server_stop`。
- **系統互動**：唯一外部互動是 Edge 無頭轉檔（本機程序），無任何網路資源請求。
- CSP、零 inline script、零 SQL、artifact 唯讀等既有 webapp 邊界全部沿用。

### 相容、遷移與技術限制

- `seat_id`（含歷史名 `counter-evidence`）與 `output_dir` **永不改**：歷史 run 目錄、提供者對應（`ANTIGRAVITY_SEAT_IDS`）、賽前預檢全部綁著它。
- roster schema 升版後，預檢與測試 fixtures 同步更新。
- **已核准的已知代價**：舊 run 逐字稿中第七席自稱「反證稽核員」，標籤卻顯示「基本面研究員」。
- `ContrastTest` 直接從 token 表計算 WCAG AA，不維護第二份色值。
- 頁尾誠實：會寫檔的頁面不得沿用唯讀頁尾（PDF 匯出頁屬會寫檔）。
- 無殘留執行緒。
- 離線 bundle 導覽只能包含真實存在的檔案；`run_verifier` 會檢查每個相對連結目標存在。
- 設計參考 taste-skill 與 ui-ux-pro-max-skill clone 至工作區並記錄 commit SHA（比照 research skill 慣例），不進 Code Root。

## 驗收條件

### A1 入口與停機

- 雙擊「開啟辯論室」捷徑後，沒有任何主控台黑框出現，瀏覽器直接開到主頁。
- 伺服器已在跑時再次雙擊捷徑，不產生第二個伺服器程序，只開瀏覽器。
- 按頁面右上角「關閉伺服器」後，伺服器停止，且該次記錄到 `server_stop`。
- 「關閉辯論室」備援捷徑同樣能停掉伺服器。
- 工作區根目錄不存在 `辯論室預覽.html` 與 `開啟辯論室.bat`。

### A2 規則生效、報告可點、PDF 落地

- 在設定頁改規則並存檔後，重新整理頁面即顯示新值（規則值不得在模組層被凍結）。
- run 產出後，右上角「市場報告」與「完整辯論」皆可點開；尚未產生時為停用狀態。
- 按「匯出 PDF」後，該 run 資料夾出現 `report.pdf` 與 `debate.pdf`，且該 run 既有檔案全部未被修改。
- 匯出失敗時顯示誠實錯誤頁，run 資料夾不留半成品。

### A3 換套與標的選單

- 台股題的七席在 webapp 與離線報告顯示**股票套**名稱與研究方向，兩處一致。
- 幣題的七席顯示**幣圈套**名稱與研究方向。
- 台股題的離線報告中不出現任何幣圈席名。
- 發問流程可用選單選定資產類別與標的，不依賴純文字解析。
- roster 缺席位或缺任一套組時，載入即失敗並給出可讀錯誤，不靜默降級。

### A4 保護區與全站綠燈

- 動態聊天室、燈位、正方／反方／無法判斷票數的行為與改版前一致。
- 全站測試全綠。
- 對比度以實測數字呈報，達 WCAG AA。

### A5 全繁體中文

- webapp 頁面實際渲染後 grep，畫面上沒有英文**資料原值**。
- 「資料原值」的定義沿用 Ticket 13：權威詞彙表已涵蓋的狀態／枚舉值（如 `tw_stock`、`open`、`green`、`hit`、`pending`）不得以英文原樣出現。
- **不在此限**（屬資料本體，非枚舉）：標的代號（`2330`、`AAPL`、`BTC`）、`run_id`、`seat_id`、evidence ID。
- 離線報告版面本次不動，不納入本條驗收；其回歸由既有測試守住。

## 測試決策

### 公開行為

以下為必須被測試釘住的公開行為：

- roster `profiles` 載入的 fail-closed 條件（缺席位、缺套組、缺欄位）。
- 資產類別 → 套組的選擇規則（含跨類與開放題落到 open）。
- 歷史與命中率合併頁的內容組成，以及 `GET /stats` 轉跳到 `/history`。
- PDF 匯出端點的成功與失敗兩條路徑（含失敗不留半成品）。
- 停機端點：先回應、後停機、寫 `server_stop`。
- 標的表單送出 → launcher 收到的 `assets`／`asset_class` 參數。
- 設計 token → 對比度計算的 WCAG AA 斷言。
- 保護區行為（聊天室、燈位、三種票數）不因改版改變。

### 測試接縫

新接縫：

- roster profiles 載入器（可指定設定路徑，缺套／缺席 fail-closed）。
- 合併頁與 `/stats` 轉跳。
- PDF 匯出 handler（注入**假轉換器**，不真的叫 Edge）。
- shutdown handler。
- 標的表單 → launcher 參數傳遞。

沿用接縫：注入時鐘、fake provider、暫存目錄。

### 既有測試模式

- unittest，測試置於既有 `tests/` 慣例位置。
- 暫存目錄承載 run artifact 與設定檔，不碰真實資料根。
- 驗收基準：既有全綠 ＋ 渲染後繁體中文 grep ＋ 對比度實測數字。
- 環境無瀏覽器，不得假稱有截圖；證據以渲染後 HTML 存檔加關鍵元素斷言呈現。

### 不應耦合的實作細節

測試不得斷言以下內容：

- 樣式表的具體字串、CSS 類名順序或色碼字面值（色值由 token 表推導，斷言對比度結果而非字面色碼）。
- HTML 的 DOM 巢狀結構細節。
- Edge 無頭模式的實際命令列組成（透過注入的轉換器介面驗證，不驗證外部程序參數）。
- roster JSON 的鍵排列順序。
- 離線報告的版面字串（版面本次不動，回歸以既有測試守住）。

## 不在範圍內

- 開放題中性第三套的完整研究方向設計。
- 離線 HTML 報告的版面改版。
- 離線報告 renderer 的版面調整——**唯一開口是席位標籤來源**，其餘不動。
- 行動版專屬佈局。
