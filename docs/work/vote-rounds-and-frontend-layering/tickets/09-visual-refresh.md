# 09 — 視覺升級

- Spec：`../spec.md`
- Blocked by：08 webapp 分層搬家
- 需求覆蓋：R-011、R-012（保護區）

## 交付成果

在既有設計系統（Google 風白底、毛玻璃、微軟正黑體、語意色）內，以 Gemini 建議為參考方向升級 `site.css` 與元件結構：按鈕／輸入框過渡動畫與 focus ring、聊天氣泡與頭像對齊優化、表格 hover 與表頭樣式（全大寫加寬字距）、badge 精緻化、席位卡 hover 回饋。語意色（正反棄、五燈）與保護區行為不動；概述摺疊行為保留。

## 驗收條件

- 對比度實測（含毛玻璃合成色）達 WCAG AA，數字由測試輸出。
- 渲染後 grep 無英文資料原值；零外部資源（無 CDN／外部字型）。
- 保護區行為斷言與改版前一致；概述測試全綠；全套件測試（WSL）全綠。
- 使用者視覺走查確認（最終驗收由使用者判定）。
