# 02 — 四輪投票狀態機

- Spec：`../spec.md`
- Blocked by：01 規則檔 schema v2 與載入器
- 需求覆蓋：R-001（時間表）、R-002（盲投直過）、R-005（硬停結算）

## 交付成果

狀態機以輪陣列運作：每輪在牆上開票，領先立場票數達該輪門檻即結案，stop_reason 可追溯到該輪；七席開場票全部到齊且同一立場時立即結案（藍燈路徑，不等牆）；硬停時刻做最終結算——領先立場達末輪門檻即採納，否則未達共識；回合驗證與停止判定由輪陣列迴圈推導，不寫死輪數；有效票＝開票當下該席最新公開立場，不再依賴挑戰完成。

## 驗收條件

- 假時鐘模擬單幣題：5:00／7 票、6:30／6 票、8:00／5 票、9:30／4 票、10:00 結算逐一驗證；比較題（封存 4:30）同一組斷言全部 +30 秒成立。
- 七席開場票全到且同立場→立即結案、stop_reason 為盲投直過；六同一異→5:00 開票不結案，6:30 達 6 票才結案。
- 最終結算：領先 4 票→採納（燈號依票數映射為橘）；領先 3 票→未達共識、紅燈路徑。
- `votes.json` 與 `debate.jsonl` 的 stop_reason 與輪次可追溯；燈號映射（7藍／6綠／5黃／4橘／<4紅）不變。
- 全套件測試（WSL）全綠。
