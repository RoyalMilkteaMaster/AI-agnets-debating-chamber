# 04 — 證據可見性閘門（提示詞層）

- Spec：`../spec.md`
- Blocked by：03 Driver 編排與挑戰退役
- 需求覆蓋：R-003

## 交付成果

第一輪開票前，每席提示詞的證據區塊只含該席 `seat_id` 的證據卡；第一輪未過後，所有後續提示詞恢復完整快照注入（＝JSON 資料交換）。`prompt_builder` 支援 per-seat 證據視圖，契約改為「同階段內七席共用區塊逐位元相同」。封存快照檔案與 run 檔案契約零改動。

## 驗收條件

- fake provider 捕捉提示詞：開場／整理階段七席各自只見自席證據卡（含互斥斷言：任一席提示詞不含他席證據 ID）；交換後階段七席證據區塊逐位元相同且含全部證據卡。
- 7/7 盲投直過的 run：從頭到尾沒有任何一席的提示詞含過他席證據。
- `evidence.jsonl` 與快照檔案的產生流程、內容與欄位與改版前一致（run 檔案契約零改動）。
- 全套件測試（WSL）全綠。
