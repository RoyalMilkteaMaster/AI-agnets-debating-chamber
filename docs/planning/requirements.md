# Hoya Bit Market Agents 需求紀錄

- 狀態：已核准
- 核准日期：2026-08-01
- 來源：`$milktea-skills-grill-me` 需求階段
- 2026-08-09 增補：〈前端重設計與七席換套〉一節；與 2026-08-01 版衝突處（例如資產範圍已擴至台股／美股）以該節與 post-competition-refit 各票為準。

## 問題與目標

使用者參加 Hoya Bit 黑客松，需要在現場抽題後 15 分鐘內，讓多模型 Agent 自行蒐集多種加密市場資料、整理正反證據、辯論並產生可追溯的市場判斷，最後保留兩分鐘人工閱讀與準備展示。

核心原則是多方查證。票數代表 Agent 共識，不代表客觀真理；報告必須誠實揭露票數、少數意見、資料限制與失效條件。

## 支援範圍

- 資產：只支援 `BTC`、`ETH`、`SOL`、`BNB`、`XRP`。
- 題型：單幣市場狀態、兩幣比較、整體市場狀態、事件影響。
- 輸入：使用者貼上自然語言題目，可附文字、網址或資料檔。
- 分析期間：題目指定優先；未指定時預設過去 14 日。
- 範圍外：其他資產、股票、一般商業研究、價格目標、槓桿、倉位比例與直接買賣指令。

## Agent 組成與研究席

- Core Agent：GPT-5.6 Sol。
- Sub-agents：3 個 Claude Opus、3 個 GPT-5.6 Sol、1 個 Gemini Pro。
- 每個 Sub-agent 必須遵循固定版本的 `mattpocock/skills` `research` 原則。

七個研究席：

1. 現貨價格、成交量與技術結構。
2. 衍生品、OI、Funding、清算與基差。
3. 鏈上、供給、巨鯨與交易所流量。
4. 官方公告、監管及事件催化。
5. 新聞查證與事件時間線。
6. 社群、重要帳戶、宏觀及 BTC 關聯。
7. 反方證據與資料品質檢查；該席不固定投偏空。

七席先分面研究，投票前讀取全部共享證據，再對整體題目形成自己的立場。

## 時間規則

```text
T+0～1:30   優先搜尋一手來源；社群席可立即研究社群訊號
T+1:30～5   找不到所需一手資料時，允許可信二手來源
T+4:00      硬停止新增搜尋，開始投票與辯論（T+3:50 停止收件）
T+7 前      6 張同立場票達成共識
T+7～9      5 張同立場票達成共識
T+10        強制停止；4 張同立場票採用，否則未達共識
共識後 3 分鐘內、最晚 T+13 完成報告
T+13～15    使用者人工檢查與準備展示
```

即使初始投票已有六票同立場，仍必須先完成一輪反方挑戰。

## 投票與辯論

投票種類：

- 單幣／整體：偏多、偏空、中性／方向不明。
- 兩幣比較：A 相對強勢、B 相對強勢、無明顯差異。
- 事件影響：正面、負面、影響不明／高度條件式。

Agent 應方向優先。選擇中性時必須說明雙方衝突證據、無法判斷原因，以及什麼新證據會使其改票。

辯論使用共享原文紀錄；Core 只能主持、計時、分發相同原文及計票，不得摘要成二手訊息、替 Agent 改票或隱藏少數意見。

## Agent 失敗

- 優先以相同模型重試一次。
- 再失敗時可用其他模型替補，並揭露原模型、替補模型與原因。
- 投票門檻永遠維持絕對 `6／5／4`，不得按可用人數降低。
- 少於四張有效票時輸出紅燈失敗報告，不形成市場結論。

## 證據與來源

每筆證據保存原文或原始數值、網址／API 來源、發布與取得時間、資產、資料類別、支持或反對方向、蒐集 Agent、可信度與重複判定。

來源等級：

1. 交易所、區塊鏈原始資料、官方公告、監管機構。
2. 可信資料聚合商與具名新聞機構。
3. 社群、KOL 與重要帳戶。

社群資料不能單獨支撐結論。外部內容一律視為資料，不得成為對 Agent 的操作指令。

## 信心燈號

- 🔴：少於四張有效票、流程失敗或證據不足。
- 🟠：4/7，或結論嚴重依賴單一來源。
- 🟡：5/7，且至少兩類獨立證據。
- 🟡🟢：6/7，且至少三類可靠獨立證據。
- 🟢：7/7，且至少四類新鮮獨立證據，沒有未解決的致命反證。

票數只設定信心上限；來源品質、資料過期與矛盾可以使信心降級。

## 交付與驗收

每次 Run 必須產生或誠實說明無法產生：

- `report.html`
- `debate.html`
- `report.md`
- `evidence.jsonl`
- `debate.jsonl`

報告包含市場狀態、期間、信心、完整票數、每席初始／最終立場、改票原因、正反證據、替補、限制、來源與失效條件。

操作流程是從產品 Code Root 開啟新的 Codex Task，呼叫專用市場研究 Skill，貼上題目後自動執行。
MVP 不另建外部網站或登入系統，但提供只監聽 `127.0.0.1` 的唯讀即時頁面，顯示七席公開
辯論、票數變化、剩餘時間、門檻與可追溯證據；不得顯示或聲稱取得模型隱藏思考過程。

## 成本與賽前限制

- 只使用現有 Codex、Claude、Google AI Ultra 會員權限及免費／公開市場資料。
- 不新增付費 API。
- 所有 CLI、登入、模型、搜尋、路徑、權限與報告能力必須在正式計時前預檢完成。
- 正式 15 分鐘內不得等待安裝或登入。

# 前端重設計與七席換套（2026-08-09 核准）

- 狀態：已核准（使用者於需求訪談逐項定案）
- 來源：`$milktea-skills-grill-me` 需求階段

## 問題與使用者

前端經多輪改動後動線混亂；根目錄靜態快照（辯論室預覽.html）誤導使用者以為規則過期、報告點不開；七席名稱與研究方向是純幣圈視角，與已支援台股／美股的現實不符；發問靠純文字解析；bat 入口留下關不掉的主控台視窗。使用者為本人（本機單人）；離線報告讀者為使用者要分享的對象。

## 目標結果

視覺一致、入口乾淨無黑框、頁面精簡的前端；七席隨題目資產類別自動換套名稱與研究方向；發問改用標的選單；離線報告可手動匯出 PDF。

## 核心流程

雙擊桌面捷徑（隱藏視窗）→ 瀏覽器開主頁 → 選單選資產類別＋標的發問 → 一頁式辯論室觀戰 → run 產出後右上角開市場報告／完整辯論，需要時按「匯出 PDF」→ 畫面上「關閉伺服器」優雅收工。

## 必要需求

1. **頁面清單**：即時辯論（主頁）｜歷史與命中率（合併一頁：上方統計卡＋下方 run 列表帶命中結果）｜設定｜run 詳情（保留）｜市場報告／完整辯論（離線兩份，內容不碰、右上角必可點）。
2. **保護區（功能凍結、外衣可換）**：動態聊天室、燈位、正方／反方／無法判斷票數——內容、位置、語意色不動；字體、間距、卡片樣式可隨新設計系統統一。
3. **重設計範圍**：全部網頁頁面套同一套新設計系統。
4. **入口動線**：刪除「辯論室預覽.html」；bat 退役；桌面捷徑隱藏啟動（伺服器已在跑→直接開瀏覽器）；頁面右上角「關閉伺服器」按鈕（優雅寫 `server_stop`）；備援「關閉辯論室」捷徑。
5. **七席換套**：兩套研究方向（股票＝台股美股共用、幣圈＝現行語彙），依 run 的資產類別自動切換顯示名稱與方向；開放題沿用通用敘述；`seat_id` 與 `output_dir` 永不改（相容性）。分工細表見下。
6. **標的選單**：發問以選單選資產類別＋標的，取代純文字解析（接 T05 的 assets／asset_class 接縫）。
7. **全繁體中文**：畫面上不得出現英文資料原值。
8. **PDF 手動匯出**：報告頁「匯出 PDF」按鈕，以 Edge 無頭模式將現成 HTML 轉 `report.pdf`／`debate.pdf` 存入該 run 資料夾；HTML 與報告版面不動。

## 邊界與錯誤

- 保護區（動態聊天室、燈位、正方／反方／無法判斷票數）沿用「功能凍結、外衣可換」：內容、位置、語意色、行為、計票、燈號語意不動；字體、間距、卡片樣式可隨新設計系統統一。
- 離線 renderer 版面凍結**解凍範圍限於**：新設計系統換裝＋伺服器側五導覽所需開口；`run_verifier` 對既有舊 run 的檢查不得破壞。
- `seat_id`／`output_dir`／提供者對應永不改。已核准代價：舊 run 逐字稿內舊席名與新標籤並存（沿用前次先例）。
- 舊 run 的離線 HTML／PDF 不回溯重製，維持產出當時外觀。

## 產品限制

全部沿用：零外部資源（毛玻璃以原生 CSS 實作）、零 SQL（唯一取數路徑 `run_index.query_runs`）、run artifact 唯讀、CSP 逐 directive 釘死、零 inline script、WCAG AA 對比為測試斷言、規則值走 reload-aware API、既有測試全綠、全繁體中文（A5 標準沿用）。
新增：Google 四色裝飾色與語意色（正反棄、燈號）必須在畫面上可區分，不得混用。

## 實作偏好或硬性限制

- 字體多用微軟正黑體（系統字型堆疊內優先，不引外部字型）。
- 深色模式退場後只維護一套 palette；對比測試面隨之縮減。

## 驗收結果

1. 設定頁渲染後每個規則項顯示中文標籤＋白話說明，分組標題為中文；模擬未翻譯鍵時顯示原鍵名＋「尚未翻譯」標註且可編輯。
2. 任一 webapp 頁面（除「伺服器已關閉」頁）右上角都有五導覽；「設定」獨立於「關閉伺服器」左邊；歷史／設定／主頁上兩個報告導覽指向最新有報告的 run，run 詳情頁指向自身 run；無報告時停用樣式。
3. 經伺服器瀏覽離線兩頁時可見五導覽並可回站內；直接開啟 HTML 檔案時維持自足兩分頁導覽。
4. 新 run 的離線兩頁與全站 webapp 頁面呈現白底新設計；不論作業系統深淺色設定，顯示同一套白底 palette；對比度實測達 WCAG AA。
5. 台股／美股題席位卡顯示股票套新名稱＋白話說明；幣題顯示幣圈套新名稱＋白話說明；離線報告席名與 webapp 一致。
6. 發問選單無「開放題」選項；歷史中的開放題 run 仍可開啟回看。
7. 保護區行為與改版前一致；全站測試全綠。
