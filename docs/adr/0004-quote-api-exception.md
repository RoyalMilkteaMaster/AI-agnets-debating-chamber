# ADR 0004：事後驗證允許單一免費報價 API（研究管線維持不抓行情）

- 日期：2026-08-05
- 狀態：已核准

## 背景

架構 §3.1 明定 Python 不爬網站、不預抓行情，市場資料全由七席自行搜尋。賽後續用新增「事後驗證（對答案）」需求：預測到期後記錄實際漲跌並統計各燈號命中率。若無自動價格來源，只能靠使用者手動輸入，追蹤會斷。

## 決策

新增 `hoya_market_agents/quote_api_client.py` 作為免費公開報價 API 的唯一介接點，僅供常駐前端的到期檢查讀取收盤／現價，寫入該 run 的 `outcome.json` 與 index.db。研究、辯論、報告管線一律不得呼叫此模組。API 失敗時前端提供手動輸入 fallback。

## 理由

- 事後驗證是純客觀對帳（拿一個價格數字），不涉市場判斷，不會汙染「七席自行研究」的核心設計。
- 限免費公開 API，維持「不新增付費 API」的既有限制。
- 單一介接點＋管線隔離，讓破例範圍可稽核、可回收。

## 主要後果

- 系統首次出現對外部資料服務的程式化依賴；API 改版或失效時，事後驗證退化為手動輸入（有既建 fallback）。
- 台股／美股／crypto 需各自對應報價來源，代號解析錯誤會記錯答案——outcome.json 保留來源與原始回應以供追查。
